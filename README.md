# DispatchContainers

Диспетчерская контейнерных перевозок: веб-панель для диспетчера и администратора
+ бот в мессенджере MAX для водителя.

Панель ведёт заявки, маршруты и остановки, справочники, уведомления и тревоги.
Водитель работает в MAX: получает карточку заявки, отмечает прибытие и выполнение
операций, прикладывает фотографии и комментарии. Диспетчер видит всё это в панели
и управляет доступами сотрудников.

## Стек

| Слой | Технология |
|---|---|
| Рантайм | Bun 1.3 |
| API | Hono + oRPC (типизированный RPC) |
| ORM | Drizzle ORM |
| БД | PostgreSQL 16 |
| Фронт | React 19 + Vite 7 + Tailwind CSS 4 |
| Обратный прокси | Caddy (TLS автоматически) |
| Развёртывание | Docker Compose |

Приложение **не использует серверный рендеринг**: фронт — SPA, один процесс Bun
отдаёт и API, и статику.

## Структура

```
packages/web/src/
├── api/
│   ├── core/app.ts        ← сборка Hono: CORS по белому списку, заголовки безопасности
│   ├── cron.ts            ← внешний триггер планировщика /api/cron/tick
│   ├── database/          ← схема (PostgreSQL) и клиент Drizzle
│   ├── lib/
│   │   ├── access.ts      ← допуск, блокировки, авто-приостановка
│   │   ├── audit.ts       ← журнал административных действий
│   │   ├── personal-data.ts ← выгрузка и стирание ПДн (ст. 14–17 152-ФЗ)
│   │   ├── scheduler.ts   ← планировщик: напоминания, тревоги, эскалация
│   │   ├── settings.ts    ← настройки
│   │   └── webhook-check.ts ← проверка достижимости вебхука и сертификата
│   ├── max/               ← адаптер Bot API MAX: сообщения, подписки, подпись initData, TLS
│   └── routes/            ← процедуры oRPC (auth, staff, requests, settings, sessions, ...)
└── web/                   ← React-фронт: страницы, компоненты, хуки, запросы

scripts/                   ← эксплуатация: развёртывание, бэкапы, сторож вебхука
packages/web/scripts/      ← смоук-тест PostgreSQL
packages/web/drizzle/      ← SQL-миграции
certs/                     ← корни Минцифры для исходящих запросов к MAX
```

## Быстрый старт на VPS

```bash
git clone git@github.com:xenus91/DispatchContainers.git
cd DispatchContainers
bash scripts/bootstrap-fresh.sh --domain example.ru --admin-phone 79001234567
```

Скрипт поставит Docker, откроет порты, развернёт приложение, создаст `.env`
со случайными секретами, применит миграции и поднимет панель на HTTPS.
Полная инструкция: [`docs/NEW-VPS-FROM-SCRATCH.md`](docs/NEW-VPS-FROM-SCRATCH.md).

## Быстрый старт (локально)

```bash
bun install
cp .env.example .env      # заполнить DATABASE_URL, MAX_BOT_TOKEN, SEED_ADMIN_PHONE
bun run db:migrate        # применить миграции
bun run dev               # http://localhost:4200
```

## Команды

| Команда | Что делает |
|---|---|
| `bun run dev` | дев-сервер панели |
| `bun run build` | типизация + продакшн-сборка фронта в `packages/web/dist` |
| `bun run start` | продакшн-сервер (API + статика) |
| `bun run typecheck` | проверка типов |
| `bun run lint` | oxlint |
| `bun run format` | oxfmt |
| `bun run db:generate` | сгенерировать миграцию из схемы |
| `bun run db:migrate` | применить миграции |
| `bun run db:smoke` | смоук-тест PostgreSQL (29 проверок, чистит за собой) |
| `bun run db:push` | применить схему напрямую (только для локальной разработки) |

о местоположении, фотографии документов, ИНН клиентов. Размещение базы данных
на территории РФ, порядок обработки, согласия и права субъекта описаны
в [`docs/152FZ.md`](docs/152FZ.md).
